# Portfolio direction

## Intent

An English personal showcase for an employed designer. Clean, timeless, visually striking, with a restrained spatial quality. Minimal homepage language, no availability claim, no sales pitch. Keep the closing line: **What could we make possible?**

## Implementation plan and decisions

1. Audit original content and responsive failures. Full-page background covers cropped photographs; the homepage lacked a mobile viewport. Replaced the slideshow architecture with native scrolling and project routes.
2. Preserve the work and credits. Six entries cover every original project photograph, the 4D-printing simulation video, the award. No professional clients or employment history were invented.
3. Establish a quiet gallery system: warm paper, graphite, chrome, and the original coral accent. The original GitHub avatar is rebuilt as SVG and used for the primary identity. A matching ten-cube assembly forms the interactive study. The approved spherical design is a faint, blurred coral background motif. Panel surfaces use warm stone and white; no green tint or decorative stars.
4. Keep mobile framing intact. Single-column cards, intrinsic gallery ratios, containment, full-image links, accessible menu and filtering, keyboard-accessible configuration controls, reduced motion and WebGL fallback.
5. Prepare and deploy on the existing Vercel project, with Analytics, free Speed Insights, and OpenTelemetry. Preserve production domain and protection settings.
6. Verify content completeness, image privacy, static builds, local mobile rendering, production routes, and a live server trace.

## References studied

- [Bruno Simon](https://bruno-simon.com/): interaction can demonstrate craft. The game-world navigation was deliberately not adopted.
- [Lusion](https://lusion.co/): a prominent visual experience plus a direct work index.
- [Jesse Zhou](https://www.jesse-zhou.com/): spatial composition; the game-oriented approach was rejected for this portfolio.

These are inspiration references, not copied layouts, code, or assets. The direction follows the owner's preference for a sculptural visual presentation.
